# Mapping Viable Areas for Agrivolatics in Saskatchewan

Static Vite site for presenting the results of a GIS-based agrivoltaics analysis.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The current page uses placeholder text and placeholder visual blocks.
- Replace those placeholders with the final hero image, maps, charts, and citations when they are ready.
- The project is structured for simple deployment on Vercel.
